## 切换楼层后电梯停靠位置修复
- 根因：3D `buildLift3D()` 与运行逻辑把 `l.stop` 的绝对标高（mm）直接当世界 y（米），而当前层几何基准是 y=0，上楼层会悬空 / 停在旧位置。
- 3D 新增 `liftFloorY(l,k)`：把 `l.floors[k]` 绝对标高减去 `floorY()` 转成相对当前层的米数；`liftBaseOf / buildLift3D / stairH` 也用同样换算。电梯运行各阶段（调度、起步、途中改站、显示屏跳层、按钮提示、到站消灯）全部改用相对高度，`l.stop` 仍保存绝对标高供 2D 标注。
- 重要纠正：不能在 `switchFloor()` 里把电梯 `cur/stop` 改成当前楼层——用户在电梯面板「楼层设置」里手设的停靠高度会被覆盖。切层 / 增删层不再触碰电梯数据；`syncLiftsToFloors()` 只在楼层缺失时初始化，手设值保留；`fixState()` 内联同样逻辑（此时 `state` 尚未初始化）。门洞 `liftFloor` 按所联动电梯的楼层数钳制，不再按建筑楼层数。

### 道路尺寸问题修复（2026-11-23，用户反馈「尺寸不对吧」）

### 道路车道横断面重构（2026-11-23，用户反馈「宽度有点宽？是不是没画清楚车道数？」）

- 新模型：`laneW`（单车道宽 mm）+ `lanes`（每向车道数）+ `medianW` + `shoulderW`，默认 `w = medianW + 2×(lanes×laneW+shoulderW)`，保证标称宽度与车道数自洽。默认：高速 2 车道×3.75m + 3m 分隔带 + 4m 双肩 = 26m；公路 1×3.5m + 1m 双肩 = 9m；城市道路 2×3.5m + 1m 双肩 = 16m；乡村 1×3m = 6m。小道/人行道无车道概念（`laneW` 缺省）。
- 核心函数 `roadLayout(e)` 定义在 classic script 顶层，2D（mm）与 3D（m，偏移 /1000）共用；返回 `{st,lanes,median,scale,refW,lines:[{kind:'lane'|'edge',off}]}`。`scale` 限制 0.2~5，改路宽时所有标线按比例缩放，改车道数时路宽重算到标准值。
- 标线规则：中央分隔带按 `medianW` 画多边形并两侧加白边；同向车道间用 `st.mark` 虚线；车道与路肩之间用 `st.edge` 实线；中心线三态 `centerStyle: 'dash'|'double'|'none'`（高速用 none 因为已有分隔带）。
- 属性面板新增 `#exLanes`（1~8），onchange 里 `e.lanes=v` 且重算 `e.w`；切换道路类型时 `delete e.lanes` 回落到新类型默认。面板说明、按钮 toast、README 中英文、CHANGELOG「优化」均已同步。
