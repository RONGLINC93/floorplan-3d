## 楼层复制 / 删除确认修复
- `renderFloorBar()` 中 `#flDel` 原写法 `if (uiConfirm(...)) deleteFloor()` 把 Promise 当布尔值，弹窗一出现就删除；`#flCopy` 无确认。
- 两者都改为 `async` 事件处理器，`await uiConfirm(...)` 后再执行，取消不改变楼层。确认文案带楼层名并说明可 Ctrl+Z 撤销。

## 框选对象跨楼层复制 / 移动
- 多选面板 `multiPanel()` 新增目标楼层下拉（排除当前层）、`multiCopyFloor` / `multiMoveFloor` 按钮；无其它楼层时禁用。移动操作先 `await uiConfirm(...)`，复制直接执行。
- 新增 `XFLOOR_KEYS`（kind → state 数组键）、`xfloorBucket()`（确保目标层 `byFloor` 数据完整）、`xfloorRemap()`（递归替换 id 字符串）、`xfloorHasWall()`、`xfloorNewId()`、`transferMultiToFloor(mode,targetId)`。
- 逻辑要点：先 `snap()` 存档 → 取目标层 bucket → 为复制对象生成新 id（移动仅在目标层已有同 id 时重生成）→ 墙先写入目标层，门窗按新墙 id 改引用 → 再写其它构件与房间 → 移动时从当前层删除原件。
- 墙上的门窗自动随墙转移；`lbay` 的 `legs[].wall`、灯具 / 电箱的 `wall` 引用都由 `xfloorRemap` 重建。目标层缺少对应墙时跳过该门窗并计数提示；移动时只删除真正转移成功的门窗，避免数据丢失。
- 房间：`state.rooms[id]` 与 `bover['R'+id]` 复制到目标层；自画房间（id 以 X 开头）连 `roomsExtra` 几何一起搬运，复制时重生成 id。原始房间沿用原 id（各层独立 rooms 表）。
- 电梯 `lift` / 轴网 `axgrid` 是整栋共享字段，不在 `FLOOR_KEYS`，跨层操作跳过并提示。

## 下层参照显示开关
- 用户最终定名「下层参照」（最初叫「下层虚影」）。楼层条按钮显示「下层参照」，英文 Below reference；tooltip 写明「显示 / 隐藏紧邻下层墙体的半透明参照（2D 与 3D）」。内部字段仍叫 `ghost`，避免影响已保存方案。
- `ui.layers` 增加 `ghost: true`（默认开），随 `serializePlan()` 的 `layers` 字段保存 / 还原；楼层条按钮 `#flGhost` 按 `ui.layers.ghost` 高亮，点击切换后 `scheduleAutoSave()` + `renderAll()` + toast。
- 2D：`renderGhostWalls2()` 开头判断 `ui.layers.ghost`，关闭时清空 `#gGhost` 并移除 `data-ghost-of`。
- 3D：`sync()` 的架构签名加入 `ui.layers.ghost` 使切换能触发重建；`buildFloorPlates()` 关闭时先释放 `plateGroup` 再返回，开启时照常生成下层幽灵墙。

## 墙高跟随楼层高度修复
- 根因：普通墙默认 `cwHOf()` 写死 2800mm，弧形墙新建默认 `h:2800`、3D fallback 也写死 2800；墙高输入 `max=6000` 而楼层高可到 12000；3D `opt.cut` 初始 2.8 且只在进入漫游时抬高，鸟瞰默认墙仍是 2.8m。
- `cwHOf(id,k)` 普通墙缺省改为 `currentFloorH()`；矮墙 1000、玻璃矮隔断 1200 保持。弧形墙新建默认 `h: currentFloorH()`，3D 弧形墙 fallback 同步。
- 墙属性面板 `wH` / `bwH` 与弧形墙 `awH` 的 `max` 改为 12000；无单独设定值时输入框留空，placeholder 显示「跟随楼层 N」，面板提示说明留空即通顶。新增「墙高同楼层」按钮，点击清掉 `state.wallH[id]` / `w.h` 恢复跟随。
- 3D 增加 `opt.full` 标志区分「全高墙」与「剖切墙」：全高墙模式下 `sync()` 把 `opt.cut` 自动对齐 H，`syncCutBtns()` 按 `opt.full` 高亮；剖切墙模式 `opt.cut` 保持 1.2。漫游进入时也按 `opt.full` 判断，不再误改剖切模式。
- 跨层搬运墙体时同步搬运 `state.wallH[wallId]` 到目标层新 id，移动时删除源层该映射。
