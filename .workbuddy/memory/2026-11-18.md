## 多联开关各开各的（双/三/四开独立控灯）
- 需求：双开/三开/四开开关每一联独立控制不同灯组，3D 点哪个翘板切哪联。用户确认方案：面板按联勾选 + 3D 点具体翘板。
- 数据结构：开关加 `ctlByGang`（二维数组，ctlByGang[g]=第g联灯 id），fixState 归一化。`switchTargets(sw, gang)`：多联且 ctlByGang[gang] 已配置时只取该联，否则回退整开关 ctl；不传 gang 返回全部（兼容既有调用）。
- 3D：`wallSwitch` 建模里每个 rocker 单独 `tagPick(rocker,'lamp',id)` + `rocker.userData.gang=i`；pick() 沿父链找 pick3d 时附带 gang；落地 switch（单按钮）无多联不改。4 处 toggleLamp(h.id) 调用改为 toggleLamp(h.id,h.gang)。`toggleLamp(id,gang)` 组内每开关取 switchTargets(s,gang)。
- 指示灯：每个翘板 dot 用 glow.clone()，材质 userData.gangRef={sw,gang}，加入 lampGlowMats；applyLight 按该联灯是否全亮设 emissiveIntensity。
- 面板：`lampPanel` 反向灯具列表，gangs>1 时按联循环 boxFor(g)，每行 data-gang/data-ctg；绑定 data-ctl 按 gang 写 ctlByGang；全选按钮改 data-ctlall/data-ctlnone（值为 gang 或空=整开关）；lMode 切 list 时逐联固化 ctlByGang。
- 2D：选中开关按联画线，线中点标联号圆点①②③④；multi 判定 = gangs>1 且 ctlByGang 非空。
- 实测（Edge）：面板双联盒子勾选 L1/L2 正确；toggleLamp(SW,0) 只切 L1、toggleLamp(SW,1) 只切 L2；wallSwitch 2 个翘板 gang=[0,1]；指示灯 gang0 emissive1.2 / gang1 emissive0.05（L1开L2关）；无报错。
- 测试坑：落地 `type:'switch'` 是单按钮无多联；多联是 `wallSwitch` 且需给合法 wall（否则 openingWallGeom 报错）。gangRef 在 dot.material.userData 不在 mesh.userData。

## 新增建筑工具检查清单

除 2D 符号、3D 构件、属性面板、放置逻辑四部分外，新工具必须同时覆盖以下通用交互，不能只把工具做出来：

- **直角 / 自由约束**：两点绘制类工具默认走直角（锁水平 / 垂直）模式，按住 Shift 临时锁定轴向；统一复用 `axisLock`，与画板下方「直角 / 自由」切换保持一致。
- **框选**：纳入框选命中与包围盒计算；多选后支持整组拖动、Ctrl+D 复制、Delete 删除，多选面板显示正确类型名称。
- **选中高亮**：选中时显示橙色虚线选框与对应手柄（线性构件白色圆点、矩形构件四角方块），改动正常进入撤销历史。
- **拖拽大小**：矩形构件四角手柄缩放（对角固定、设置最小尺寸、同步属性面板数值）；线性构件两端手柄伸缩（起点固定、沿原方向延伸）。
- **命中容差**：细线 / 镂空构件补透明命中带，避免点不中而穿透到下层对象。

## 几何数据与交互一致性

- 矩形类构件统一存「中心点 + 宽深」（如轴网、楼板、电梯、阳台）；渲染、选中框、手柄、拖动必须使用同一语义，避免出现“框偏半个宽深”的问题。
- 画墙支持直角 / 自由两种模式，两种模式下按住 Shift 均临时启用轴锁定。
- 旋转工具采用 CAD 命令式流程：选中对象 → 点「旋转」→ 点基点 → 拖动预览或输入角度确认，支持 Esc / 右键取消与 Ctrl+Z 撤销；默认 15° 吸附，按住 Shift 自由角度。
- 支持长度编辑的线性构件（栏杆、梁、女儿墙、雨棚等）：起点不动、终点沿原方向伸缩。
