## 关联组传递闭包 + 灯具联动开关列表 + 悬停高亮
- 需求三连：① 开关关联线显示整组（双控↔双控→灯）；② 灯具属性加入联动开关；③ 悬停开关列表高亮开关对象。
- 公共函数 `switchGroup(ids)`（3159 附近）：从起始开关 id 沿 links 传递展开整组（links 双向绑定）；与 3D `toggleLamp` 的关联组遍历语义一致。
- `renderSwitchLinks2()`：seeds = 选中开关自身 / 选中灯则由控制它的开关，展开整组后画组内所有开关间联络线（原来选中开关只画直接相连的一对）。
- `renderSel()` 灯选中分支：seeds=控制本灯的开关→整组，画组内每个开关→其受控灯；`ui.swHover` 命中时给该开关画高亮。开关选中分支同理改用 switchGroup 整组。
- 悬停高亮样式：用户嫌最初自创的（橙红实心点 + #c0562b 粗虚线圈 dasharray 6 4）太丑，改为沿用项目标准选中高亮——`fill="rgba(181,101,58,.09)"` + `stroke="#b5653a"` + `stroke-width 1.5` + `stroke-dasharray 5 3` + 名称（12*k / #b5653a / 600 / 白描边），与柱子/灯具选中圈一致。教训：新增高亮优先复用既有 `A` 变量与选中样式，别自创配色。
- 灯具属性面板 `lampPanel()`：`isLightType` 时新增「联动开关」区块，列出所有开关（`data-swrow`/`data-swlink`），勾选态用 `switchTargets(x).some(t=>t.id===l.id)`（含半径命中），显示模式标记（半径/指定）。`bindLampPanel()`：悬停行设 ui.swHover→renderSel 高亮；勾选时若开关非 list 模式先固化 `sw.ctl=switchTargets(sw).map(t=>t.id)` 再切 list 并增删本灯，避免丢失原受控灯。`ui.ctlHover=null` 处同步重置 ui.swHover。
- 浏览器实测（Edge + playwright-cli，导入测试方案后 window.select 选中）：联动开关列表显示 A(checked)/B(unchecked)；悬停 B→画板出现 1 个 6 4 高亮圈，移开→0；勾选 B→checked，无 pageerror。
- playwright-cli 关键：本环境 Chrome 缺失，须 `open --browser=msedge`；daemon 每条命令后退出，导入→选中→悬停→检查要串在单个 `run-code` 里；选中对象用 `window.select({kind:'lamp',id})` 最可靠。
- CHANGELOG.md「新增」已同步。主脚本语法校验通过。

## 开关侧「受控灯具」反向列表高亮（与灯具侧对称）
- 需求：选中开关→属性面板显示反向灯具列表（整组实际控制哪些灯）→悬停行→画板标准样式高亮对应灯。
- 画板 `renderSel()` 开关选中分支：`ui.ctlHover` 命中的灯改用标准选中样式（淡橙 rgba(181,101,58,.09) + #b5653a 虚线 5 3 + 编号名），用 `hiLamps` Set 去重（组内多开关控同灯只画一次）；替换掉旧的橙红大圈（r=26k / #c0562b）。连线 hv 加粗仍保留。
- 属性面板 `lampPanel()`：`(isSw||isWallSw)` 时始终显示反向灯具列表。picked = list 模式取 l.ctl / radius 模式取 `switchTargets(l)` 命中；list 模式 checkbox 可编辑（带 data-ctl）+ 全选/全不选按钮，radius 模式 checkbox disabled 只读。标题说明模式。悬停绑定复用已有 `data-ctlrow`→`ui.ctlHover`。
- 浏览器实测（Edge）：选中开关→行 L(checked,disabled) + 标题正确；悬停 L→标准高亮圈从 1 变 2，移开回 1；无 pageerror。
- CHANGELOG.md「新增」已同步。主脚本语法校验通过。
- 修正（重要）：高亮最初写在 `switchTargets(sw).forEach` 循环里，导致只有受控/勾选的灯悬停才高亮，未受控灯不高亮。用户要的是「所有灯具行悬停都高亮，与是否受控/选中无关」。改为在 `ui.sel.kind==='lamp'` 分支开头、按 `ui.ctlHover` 从 state.lamps 里 `find` 任意 isLightType 灯具高亮（标准样式：淡橙圈+编号名），独立于受控循环。连线加粗仍留在受控循环。实测：list 模式 A 只控 L1，悬停未受控 L2 也高亮「吊灯 1」，移开消失。
- 教训：悬停高亮要挂在「数据全集的悬停 id → find」上，别挂在某个过滤后的子集循环里，否则未命中的行无高亮。

## 图层开关：关联线 / 灯光半径
- 需求：顶部 2D 图层开关行（#layers，尺寸/房间/家具…）加「关联线」「灯光半径」两个开关。
- 默认均 false，随方案保存（ui.layers），3D 下随 only2d 组隐藏，点击走通用 `b.onclick`→renderAll。
- 关联线：`renderSwitchLinks2()` 加 `showAll=!!ui.layers.links`；showAll 时 seeds=全部开关、展开整组画所有联络线，并额外画全部开关→灯控制线（seenT 去重）；关闭时维持原「选中才画」逻辑。选中态控制线仍由 renderSel 画，不重复（全局模式只画基础线）。
- 灯光半径：`renderLamps2()` 第 4194 行 range，`(on || showR)` 决定画圈，关着的灯用 stroke-opacity .28 区分（亮灯 .4）。showR=!!ui.layers.lightRadius。
- 实测：关联线关→0 条、开→3 条（1 联络+2 控制）；灯光半径默认 1 圈（只亮灯）、开→2 圈（含关灯）、关→1 圈；无 pageerror。
- 测试注意：欢迎遮罩 `#cloudMask` 会拦截点击，实测用 `element.click()`（evaluate 里派发）绕过，或先关遮罩。
